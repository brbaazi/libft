# Libft 📚

**Libft** is a 42 School project where I created my own C library.

The goal is to recreate useful functions from the standard C library and build additional functions that can be reused in future 42 projects.

## 🧠 Concepts

* C Programming
* Strings
* Memory management
* Pointers
* Linked lists
* Makefile
* Static libraries

## 📦 Functions

The library includes functions for:

* Character checks
* String manipulation
* Memory manipulation
* Conversion
* File descriptor output
* Linked lists

Examples:

```c
ft_strlen()
ft_strdup()
ft_split()
ft_atoi()
ft_calloc()
ft_memcpy()
ft_strjoin()
```

## 🚀 Usage

Compile the library:

```bash
make
```

This creates:

```text
libft.a
```

Include it in your C project:

```c
#include "libft.h"
```

Compile with:

```bash
cc main.c -L. -lft
```
